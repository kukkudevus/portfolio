01 · The problem

In a learn-by-doing trading product, subject matter experts make countless small decisions: how realistic the simulator should be versus how easy it is to learn from, or how accurate versus how safe for beginners. Those decisions mostly live in chats and meetings.

Documentation records what a system does, but rarely why.

When an expert leaves, the reasoning leaves too. New team members then either hesitate to change anything, or confidently “fix” something that was intentional.

02 · What I did

Reframed the question

{ STARTED WITH }

Can AI act as a subject matter expert?

→
{ BETTER QUESTION }

How do we preserve an expert’s reasoning, so anyone can ask about it later?

Defined the concept: a decision intelligence layer

A searchable record of decisions, reasons, trade-offs, and intent, able to answer questions like:

  • ■“Why does it work this way?”
  • ■“What breaks if we change this?”
  • ■“Is this a bug, or intended?”

05 · How experts feed it

The system can only capture reasoning that’s clearly stated, so I outlined how experts should explain decisions as explicit rules (“if this happens, do that, because...”) rather than gut feel. This also informed the profile for future subject matter expert hires.

06 · What came of it

The team adopted NotebookLM based on this research. For FYERS Academy, I built the project’s knowledge base: research, decisions, meeting minutes, definitions, and citations, shared with stakeholders so they can ask questions about the project anytime.

Because every answer cites its source, people can check the reasoning themselves instead of relying on whoever happens to remember it.
